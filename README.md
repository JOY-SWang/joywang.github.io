# Jieyi Wang

Personal academic site for [Jieyi Wang (Joy)](https://joy-swang.github.io). Built on a trimmed [Academic Pages](https://academicpages.github.io/) Jekyll theme.

## Local preview

Use Homebrew Ruby, not macOS `/usr/bin/ruby`:

```bash
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"
cd ~/Desktop/NUS/CV/joy-swang.github.io
bundle exec jekyll serve -l -H localhost
```

Then open http://localhost:4000. Do not run `gem install bundler` with the system Ruby.
